Ransomware

Ransomware is a type of malware that encrypts a victim's files. The attacker then demands a ransom from the victim to restore access to the data.

How to Identify

  • Watch for SMB_WRITE logs indicating mass file modification or encryption on network shares.
  • Unexpected outbound connections to unknown command-and-control (C2) servers.

Mitigation

Once detected, immediately Isolate Host. You must disconnect the infected machine from the network entirely (using the Isolation Framework) before the malware spreads to other endpoints.
