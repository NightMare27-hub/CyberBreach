SQL Injection (SQLi)

SQL Injection occurs when an attacker interferes with the queries an application makes to its database. It allows attackers to view data they are not normally able to retrieve, such as passwords or sensitive company data.

How to Identify

  • Look for HTTP_500 server errors immediately after a web request.
  • Watch for query parameters that include suspicious characters like ', OR 1=1, or --.

Mitigation

The standard fix for SQLi vulnerabilities is to apply a Patch to the application code to use parameterized queries, which prevents user input from being treated as executable code.
