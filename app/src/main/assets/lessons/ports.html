What is a port?

An IP address finds a computer. A port finds the service running on it, like an apartment number inside a building.

  • 80 HTTP (web, unencrypted)
  • 443 HTTPS (web, encrypted)
  • 22 SSH (secure remote login)
  • 23 Telnet (remote login, not encrypted)
  • 53 DNS (turns names into addresses)

Rule of thumb: every open port is a door. Close the ones nobody needs.
