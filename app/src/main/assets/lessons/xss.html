Cross-Site Scripting (XSS)

Cross-Site Scripting (XSS) is a vulnerability where attackers inject malicious scripts into trusted websites. These scripts then execute in the victim's browser, allowing attackers to steal session cookies or hijack user sessions.

How to Identify

  • Look for HTTP_REQ logs where the payload or URL contains HTML tags like <script> or javascript:.
  • Common targets are search bars, comment sections, or profile inputs.

Mitigation

To stop XSS, you must Patch the web application to properly encode/sanitize all user inputs before displaying them back on the screen.
